# Sales Performance Analysis | Excel

## Project Overview
This project analyses the Sample Superstore dataset to evaluate sales performance, profitability, customer behaviour and regional trends from 2014 to 2017.

The objective is to identify business patterns and provide actionable insights using Microsoft Excel.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Interactive Slicers
- Data cleaning and analysis

## Key Performance Indicators
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Total Orders:** 5,009
- **Profit Margin:** 12.47%

## Analysis Performed
1. Yearly Sales and Profit Analysis
2. Regional Performance Analysis
3. Category Performance Analysis
4. Sub-category Profitability Analysis
5. Discount Analysis
6. Customer Sales Analysis

## Key Business Insights
- 2017 recorded the highest annual sales of $733,215.26.
- Sales declined by 2.83% in 2015 compared with 2014.
- Sales grew by 29.47% in 2016 and 20.36% in 2017.
- The West region recorded the highest sales, at approximately $725,458.
- Technology generated the highest category sales and profit.
- Tables, Bookcases and Supplies recorded negative profits.

## Dashboard Features
- Interactive dashboard with KPI cards.
- Five visualisations covering sales, profit and customer performance.
- Region, Year and Category slicers for interactive filtering.

## Dataset
Sample Superstore dataset containing 9,994 records and 21 original columns.

## Project Objective
To demonstrate practical Excel skills in data cleaning, business analysis, data visualisation and insight generation.
