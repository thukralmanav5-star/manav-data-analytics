
# Project 02 – E-commerce Data Analysis

An end-to-end SQL analysis of the Brazilian E-Commerce Public Dataset (Olist).

## Project Overview

This project uses SQL Server to analyse e-commerce transactions, customer behaviour, product performance, seller performance, payments, and delivery operations.

## Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Project Structure

- SQL – SQL scripts and analysis queries
- Business-Insights – Business findings and recommendations
- README.md – Project documentation

## Analysis Areas

- Data exploration and validation
- Customer analysis
- Sales and revenue trends
- Product category performance
- Seller performance
- Payment analysis
- Order and delivery analysis
- Customer reviews

## Dataset

Olist Brazilian E-Commerce Public Dataset.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
